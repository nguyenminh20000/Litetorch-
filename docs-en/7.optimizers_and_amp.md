# 7. Optimizers and Automatic Mixed Precision (AMP)

LiteTorch provides standard first/second-order optimization algorithms, memory-efficient variants for large language models (8-bit, FP8, ZeRO-3), and an Automatic Mixed Precision (AMP) runtime with dynamic loss scaling.

---

## 7.1. Base Class `lt.optim.Optimizer`

All optimizers inherit from this base class:
- `zero_grad()`: Clears accumulated parameter gradients (`p.grad = nullptr`).
- `step()`: Updates parameter tensors based on computed gradients.
- `get_lr()` / `set_lr(new_lr)`: Retrieves and updates the learning rate dynamically.

---

## 7.2. Standard Optimizers

### 7.2.1. `lt.optim.SGD`
```python
optimizer = lt.optim.SGD(model.parameters(), lr=0.01, momentum=0.9, weight_decay=1e-4)
```

### 7.2.2. `lt.optim.RMSprop`
```python
optimizer = lt.optim.RMSprop(model.parameters(), lr=0.001, alpha=0.99, eps=1e-8, weight_decay=0.0)
```

### 7.2.3. `lt.optim.Adam` & `lt.optim.AdamW`
AdamW decouples weight decay regularization from gradient momentum:
```python
optimizer = lt.optim.AdamW(model.parameters(), lr=1e-4, beta1=0.9, beta2=0.999, eps=1e-8, weight_decay=0.01, offload_to_cpu=False)
```

---

## 7.3. Memory-Efficient Optimizers for LLMs

| Optimizer | Constructor Signature | VRAM Optimization |
| :--- | :--- | :--- |
| `lt.optim.AdamW8bit` | `AdamW8bit(params, lr=1e-3, beta1=0.9, beta2=0.999, eps=1e-8, weight_decay=0.01)` | Block-wise 8-bit dynamic quantization of 1st and 2nd moments, saving 75% optimizer VRAM |
| `lt.optim.AdamWFP8` | `AdamWFP8(params, lr=1e-3, beta1=0.9, beta2=0.999, eps=1e-8, weight_decay=0.01)` | Uses FP8 E4M3/E5M2 states for optimizer tensors |
| `lt.optim.ZeRO3Optimizer` | `ZeRO3Optimizer(params, lr=1e-3, beta1=0.9, beta2=0.999, eps=1e-8, weight_decay=0.01)` | Shards optimizer states across all cluster GPUs |

```python
import litetorch as lt

params = model.parameters()
opt_8bit = lt.optim.AdamW8bit(params, lr=2e-4, weight_decay=0.01)
opt_fp8 = lt.optim.AdamWFP8(params, lr=2e-4, weight_decay=0.01)
```

## 7.4. Learning Rate Schedulers

### 7.4.1. `lt.optim.StepLR`
Decays learning rate by a multiplicative factor every `step_size` epochs:
```python
scheduler = lt.optim.StepLR(optimizer, step_size=30, gamma=0.1)
```

### 7.4.2. `lt.optim.CosineAnnealingLR`
Decays learning rate using a cosine schedule:
```python
scheduler = lt.optim.CosineAnnealingLR(optimizer, T_max=1000, eta_min=1e-6)
```

Update scheduler after every epoch:
```python
scheduler.step()
```

## 7.5. Automatic Mixed Precision (AMP) & GradScaler

Training in FP16/BF16 reduces VRAM usage by 50% and improves compute throughput on Tensor Cores.

`lt.amp.GradScaler` prevents underflow in half-precision representations through dynamic loss scaling:

```python
import litetorch as lt

device = lt.auto_device()

model = lt.nn.Sequential([
    lt.nn.Linear(128, 256, True),
    lt.nn.GELU(),
    lt.nn.Linear(256, 10, True)
])
model.to(device)

optimizer = lt.optim.AdamW(model.parameters(), lr=1e-3)
scaler = lt.amp.GradScaler(init_scale=65536.0, growth_factor=2.0, backoff_factor=0.5, growth_interval=2000)
loss_fn = lt.nn.CrossEntropyLoss()

x = lt.Tensor.from_vector([0.5] * (32 * 128), [32, 128], device, False)
y = lt.Tensor.from_vector([1.0] * (32 * 10), [32, 10], device, False)

for step in range(5):
    optimizer.zero_grad()
    
    with lt.amp.AutocastGuard(True, lt.DataType.FP16):
        preds = model.forward(x)
        loss = loss_fn.forward(preds, y)
        scaled_loss = scaler.scale(loss)
    
    scaled_loss.backward()
    scaler.step(optimizer)
    scaler.update()
    
    print(f"Step {step + 1}, Loss: {loss.item():.4f}, Current Scale: {scaler.get_scale()}")
```
