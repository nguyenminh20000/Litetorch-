# 2. Installation Guide

This document provides step-by-step instructions for installing and building LiteTorch across Linux, Windows, Google Colab, and source environments.

---

## 2.1. System Requirements

- **C++ Compiler**: C++14 compliant compiler (`g++` >= 7.0, `clang++` >= 6.0, or MSVC v142+).
- **Python**: Python 3.8 to 3.12 (with `python3-dev` development headers).
- **CMake**: Version >= 3.10 (for building standalone C++ tests).
- **GPU Accelerators (Optional)**:
  - NVIDIA: CUDA Toolkit 11.8 or 12.x with `nvcc`, `cuBLAS`, `cuBLASLt`.
  - AMD: ROCm 5.x or 6.x with `hipcc`, `rocBLAS`, `MIOpen`.
  - Other: OpenCL 1.2+ compatible drivers.

---

## 2.2. Linux & Google Colab Installation

### 2.2.1. Install System Dependencies

On Ubuntu / Debian / Google Colab:
```bash
sudo apt-get update
sudo apt-get install -y build-essential python3-dev libopenblas-dev
```

On Fedora / RHEL / CentOS:
```bash
sudo dnf groupinstall "Development Tools" -y
sudo dnf install -y python3-devel openblas-devel
```

### 2.2.2. Install via pip
```bash
pip install --upgrade litetorch
```

### 2.2.3. GPU Backend Verification
Check if CUDA compiler is present in your system PATH:
```bash
nvcc --version
```
When `nvcc` is discovered, LiteTorch automatically compiles and enables native CUDA acceleration.

---

## 2.3. Windows Installation

### 2.3.1. Install C++ Build Tools

Python on Windows requires MSVC or MinGW to compile C++ extensions. Choose one of the following:

**Option A: Microsoft Visual C++ Build Tools (Recommended)**
Run PowerShell as Administrator:
```powershell
winget install --id Microsoft.VisualStudio.2022.BuildTools --exact --force --override "--passive --wait --add Microsoft.VisualStudio.Workload.VCTools;includeRecommended"
```

**Option B: MinGW-w64 GCC**
1. Download MinGW-w64 (GCC 10+).
2. Add the `bin` directory of MinGW to your system `PATH`.

### 2.3.2. Install via pip
Open Command Prompt or Terminal:
```cmd
pip install --upgrade litetorch
```

---

## 2.4. Build from Source

```bash
git clone https://github.com/nguyenminh20000/Litetorch-.git
cd Litetorch-
pip install -r requirements.txt
pip install -e .
```

Compile standalone C++ test binaries with CMake:
```bash
mkdir build
cd build
cmake ..
cmake --build . --config Release
```

---

## 2.5. Environment Variables Configuration

| Environment Variable | Default Value | Description |
| :--- | :--- | :--- |
| `LITETORCH_NO_NATIVE_GPU` | `0` | Set to `1` to disable native CUDA/ROCm and fallback to OpenCL or CPU |
| `LITETORCH_RENDEZVOUS_FILE` | None | File path used for distributed rendezvous |
| `LITETORCH_NUM_THREADS` | CPU Core Count | Worker thread count in CPU ThreadPool |

---

## 2.6. Verification Script

Run the following Python code to verify the installation:

```python
import litetorch as lt

is_gpu = lt.is_gpu_available()
backend = lt.get_backend_name()
device = lt.auto_device()

print(f"GPU Available: {is_gpu}")
print(f"Backend Name: {backend}")
print(f"Active Device: {device}")

x = lt.Tensor.from_vector([1.0, 2.0, 3.0, 4.0], [2, 2], device, True)
y = lt.Ops.matmul(x, x)
loss = lt.Ops.sum(y)
loss.backward()

print("Result shape:", y.shape)
print("Loss value:", loss.item())
print("Gradient:", x.grad.to_vector())
```
