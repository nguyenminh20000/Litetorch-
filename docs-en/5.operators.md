# 5. Operators Reference (litetorch.Ops)

The `litetorch.Ops` namespace provides all algebraic operators, activation functions, normalization kernels, loss functions, and high-performance LLM primitives.

---

## 5.1. Basic Arithmetic Operators

| Operator | Type Signature | Description |
| :--- | :--- | :--- |
| `Ops.add(a, b)` | `Tensor, Tensor -> Tensor` | Element-wise addition with broadcasting support |
| `Ops.sub(a, b)` | `Tensor, Tensor -> Tensor` | Element-wise subtraction |
| `Ops.mul(a, b)` | `Tensor, Tensor -> Tensor` | Element-wise multiplication (Hadamard product) |
| `Ops.div(a, b)` | `Tensor, Tensor -> Tensor` | Element-wise division |
| `Ops.matmul(a, b)` | `Tensor, Tensor -> Tensor` | 2D matrix multiplication via cuBLAS / OpenBLAS |
| `Ops.bmm(a, b)` | `Tensor, Tensor -> Tensor` | Batched 3D matrix multiplication `[B, M, K] x [B, K, N]` |

```python
import litetorch as lt

device = lt.auto_device()
a = lt.Tensor.from_vector([1.0, 2.0, 3.0, 4.0], [2, 2], device, False)
b = lt.Tensor.from_vector([5.0, 6.0, 7.0, 8.0], [2, 2], device, False)

add_res = lt.Ops.add(a, b)
mul_res = lt.Ops.mul(a, b)
matmul_res = lt.Ops.matmul(a, b)
```

## 5.10. Gradient Clipping

```python
import litetorch as lt

device = lt.auto_device()

p1 = lt.Tensor.from_vector([10.0, 20.0], [2], device, True)
p2 = lt.Tensor.from_vector([30.0, 40.0], [2], device, True)

total_norm = lt.Ops.clip_grad_norm_([p1, p2], max_norm=1.0, norm_type=2.0)
print("Total norm before clipping:", total_norm)
```
