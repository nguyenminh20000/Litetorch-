# 6. Neural Network Modules (litetorch.nn)

The `litetorch.nn` namespace contains object-oriented modular layers with parameter tracking, device migration, and model composition.

---

## 6.1. Base Class `lt.nn.Module`

All neural network layers subclass `lt.nn.Module`:

```python
import litetorch as lt

class CustomBlock(lt.nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.fc = lt.nn.Linear(dim, dim, True)
        self.norm = lt.nn.LayerNorm([dim], 1e-5)
        self.act = lt.nn.GELU()

    def forward(self, x):
        h = self.fc.forward(x)
        h = self.act.forward(h)
        return self.norm.forward(h)

    def parameters(self):
        params = []
        params.extend(self.fc.parameters())
        params.extend(self.norm.parameters())
        return params

    def to(self, device):
        self.fc.to(device)
        self.norm.to(device)
```

Core methods in `Module`:
- `forward(input)`: Executes forward computation.
- `parameters()`: Returns `std::vector<std::shared_ptr<Tensor>>` of trainable parameters.
- `to(device)`: Migrates all sub-modules and parameters to the destination device (`CPU` or `GPU`).
- `train()` / `eval()`: Switches training mode (affects `Dropout` and `BatchNorm`).
- `compile()`: Enables graph execution compilation.

## 6.2. Linear Layers

### 6.2.1. `lt.nn.Linear`
Standard fully connected layer:
```python
linear = lt.nn.Linear(in_features=512, out_features=256, bias=True)
```

### 6.2.2. `lt.nn.QLoRALinear`
Linear layer with Low-Rank Adaptation (LoRA) and frozen base weights:
```python
qlora = lt.nn.QLoRALinear(in_features=4096, out_features=4096, r=16, lora_alpha=32.0, has_bias=False)
```

### 6.2.3. `lt.nn.MoELinear`
Mixture of Experts layer with Top-K routing:
```python
moe = lt.nn.MoELinear(in_features=1024, out_features=1024, num_experts=8, top_k=2)
```

### 6.2.4. `lt.nn.ColumnParallelLinear` & `lt.nn.RowParallelLinear`
Megatron-LM style tensor parallel layers:
```python
col_linear = lt.nn.ColumnParallelLinear(in_features=4096, out_features=2048, has_bias=True)
row_linear = lt.nn.RowParallelLinear(in_features=2048, out_features=4096, has_bias=True)
```

## 6.3. Convolutions & Pooling (Vision)

| Layer | Constructor Signature |
| :--- | :--- |
| `lt.nn.Conv2d` | `Conv2d(in_channels, out_channels, kernel_size, stride=1, padding=0, has_bias=True)` |
| `lt.nn.Conv3d` | `Conv3d(in_channels, out_channels, kernel_size, stride=1, padding=0, has_bias=True)` |
| `lt.nn.BatchNorm2d` | `BatchNorm2d(num_features, eps=1e-5, momentum=0.1)` |
| `lt.nn.MaxPool2d` | `MaxPool2d(kernel_size, stride=-1, padding=0)` |
| `lt.nn.MaxPool3d` | `MaxPool3d(kernel_size, stride=-1, padding=0)` |
| `lt.nn.AdaptiveAvgPool2d` | `AdaptiveAvgPool2d(output_height, output_width)` |

## 6.4. Normalization, Activations, and Embeddings

```python
import litetorch as lt

embedding = lt.nn.Embedding(num_embeddings=32000, embedding_dim=4096)
norm = lt.nn.LayerNorm(normalized_shape=[4096], eps=1e-5)
dropout = lt.nn.Dropout(p=0.1)

relu = lt.nn.ReLU()
leaky_relu = lt.nn.LeakyReLU(negative_slope=0.02)
sigmoid = lt.nn.Sigmoid()
tanh = lt.nn.Tanh()
gelu = lt.nn.GELU()
softmax = lt.nn.Softmax(dim=-1)
flatten = lt.nn.Flatten()
```

## 6.5. Attention and Transformer Blocks

```python
mha = lt.nn.MultiHeadAttention(embed_dim=512, num_heads=8)
```

### 6.5.2. `lt.nn.TransformerDecoderLayer`

```python
decoder_layer = lt.nn.TransformerDecoderLayer(embed_dim=512, num_heads=8, dim_feedforward=2048)
```

## 6.6. Sequential Container (lt.nn.Sequential)

```python
import litetorch as lt

device = lt.auto_device()

classifier = lt.nn.Sequential([
    lt.nn.Linear(784, 256, True),
    lt.nn.GELU(),
    lt.nn.Dropout(0.2),
    lt.nn.Linear(256, 10, True)
])

classifier.to(device)
```
