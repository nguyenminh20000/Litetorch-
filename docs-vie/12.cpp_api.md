# 12. Hướng Dẫn Lập Trình Native C++

LiteTorch được xây dựng bằng C++14 thuần túy. Hướng dẫn này mô tả cách nhúng trực tiếp thư viện LiteTorch vào các dự án C++ độc lập mà không cần thông qua tầng Python.

---

## 12.1. Cấu Trúc Header Và Liên Kết Thư Viện

Toàn bộ API C++ được định nghĩa trong thư mục `include/litetorch/`:

| Header File | Nội dung cung cấp |
| :--- | :--- |
| `litetorch/tensor.h` | Lớp `Tensor`, `StorageImpl`, enum `DataType`, enum `DeviceType` |
| `litetorch/autograd.h` | Lớp `Node`, `SavedTensor`, `Autograd` engine |
| `litetorch/ops.h` | Không gian tên `litetorch::Ops` với các hàm tính toán nguyên thủy |
| `litetorch/nn.h` | Không gian tên `litetorch::nn` chứa các lớp `Module`, `Linear`, `Conv2d`, ... |
| `litetorch/optim.h` | Không gian tên `litetorch::optim` chứa `SGD`, `AdamW`, `GradScaler`, ... |
| `litetorch/distributed.h` | Không gian tên `litetorch::distributed` cho giao tiếp phân tán NCCL/TCP |
| `litetorch/backend.h` | Không gian tên `litetorch::DeviceBackend`, `BackendDispatcher` |

---

## 12.2. Cấu Hình Biên Dịch Với CMake

Ví dụ `CMakeLists.txt` để liên kết `liblitetorch`:

```cmake
cmake_minimum_required(VERSION 3.10)
project(MyLiteTorchApp LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 14)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

include_directories(${LITETORCH_ROOT}/include)
link_directories(${LITETORCH_ROOT}/build)

add_executable(my_app main.cpp)
target_link_libraries(my_app PRIVATE litetorch pthread dl)
```

## 12.3. Khởi Tạo Và Thao Tác Tensor Trong C++

```cpp
#include "litetorch/tensor.h"
#include "litetorch/ops.h"
#include <iostream>
#include <vector>

int main() {
    using namespace litetorch;

    Device cpu_dev(DeviceType::CPU, 0);

    std::vector<float> data_a = {1.0f, 2.0f, 3.0f, 4.0f};
    std::vector<int64_t> shape_a = {2, 2};

    auto a = Tensor::from_vector(data_a, shape_a, cpu_dev, true);
    auto b = Tensor::from_vector({0.5f, -1.0f, 2.0f, 0.1f}, {2, 2}, cpu_dev, true);

    auto c = Ops::matmul(a, b);
    auto loss = Ops::sum(c);

    loss->backward();

    std::cout << "Loss item: " << loss->item() << std::endl;
    std::vector<float> grad_vec = a->grad->to_vector();
    std::cout << "a.grad[0]: " << grad_vec[0] << std::endl;

    return 0;
}
```

## 12.4. Xây Dựng Khối Module Tuỳ Biến Trong C++

```cpp
#include "litetorch/nn.h"
#include "litetorch/ops.h"

class CustomLinearBlock : public litetorch::nn::Module {
public:
    std::shared_ptr<litetorch::nn::Linear> fc1;
    std::shared_ptr<litetorch::nn::Linear> fc2;

    CustomLinearBlock(int in_dim, int hidden_dim, int out_dim) {
        fc1 = std::make_shared<litetorch::nn::Linear>(in_dim, hidden_dim, true);
        fc2 = std::make_shared<litetorch::nn::Linear>(hidden_dim, out_dim, true);
    }

    std::shared_ptr<litetorch::Tensor> forward(std::shared_ptr<litetorch::Tensor> input) override {
        auto h = fc1->forward(input);
        auto act = litetorch::Ops::gelu(h);
        return fc2->forward(act);
    }

    std::vector<std::shared_ptr<litetorch::Tensor>> parameters() override {
        std::vector<std::shared_ptr<litetorch::Tensor>> params;
        auto p1 = fc1->parameters();
        auto p2 = fc2->parameters();
        params.insert(params.end(), p1.begin(), p1.end());
        params.insert(params.end(), p2.begin(), p2.end());
        return params;
    }

    void to(const litetorch::Device& device) override {
        fc1->to(device);
        fc2->to(device);
    }
};
```

## 12.5. Huấn Luyện Bằng Bộ Tối Ưu Hóa C++

```cpp
#include "litetorch/optim.h"

int main() {
    using namespace litetorch;

    auto model = std::make_shared<CustomLinearBlock>(32, 64, 2);
    Device dev(DeviceType::CPU, 0);
    model->to(dev);

    optim::AdamW optimizer(model->parameters(), 0.001f, 0.9f, 0.999f, 1e-8f, 0.01f);

    auto x = Tensor::zeros({4, 32}, dev, false);
    auto y = Tensor::zeros({4, 2}, dev, false);

    for (int step = 0; step < 10; ++step) {
        optimizer.zero_grad();
        auto pred = model->forward(x);
        auto loss = Ops::mse_loss(pred, y);
        loss->backward();
        optimizer.step();
    }

    return 0;
}
```
