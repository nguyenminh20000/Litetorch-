# 2. Hướng Dẫn Cài Đặt LiteTorch

Tài liệu này cung cấp các bước chi tiết để thiết lập LiteTorch trên các môi trường Linux, Windows, Google Colab và hướng dẫn biên dịch từ mã nguồn.

---

## 2.1. Yêu Cầu Hệ Thống

- **Trình biên dịch C++**: Hỗ trợ chuẩn C++14 trở lên (`g++` >= 7.0, `clang++` >= 6.0, hoặc MSVC v142+).
- **Python**: Phiên bản 3.8 đến 3.12 (kèm theo thư viện header phát triển `python3-dev`).
- **CMake**: Phiên bản >= 3.10 (dành cho việc biên dịch bộ test C++ độc lập).
- **Phần cứng tăng tốc GPU (Tùy chọn)**:
  - NVIDIA: CUDA Toolkit 11.8 hoặc 12.x với `nvcc`, `cuBLAS`, `cuBLASLt`.
  - AMD: ROCm 5.x hoặc 6.x với `hipcc`, `rocBLAS`, `MIOpen`.
  - Thiết bị khác: Trình điều khiển hỗ trợ OpenCL 1.2+.

---

## 2.2. Cài Đặt Trên Linux & Google Colab

### 2.2.1. Cài đặt các gói phụ thuộc

Trên Ubuntu / Debian / Google Colab:
```bash
sudo apt-get update
sudo apt-get install -y build-essential python3-dev libopenblas-dev
```

Trên Fedora / RHEL / CentOS:
```bash
sudo dnf groupinstall "Development Tools" -y
sudo dnf install -y python3-devel openblas-devel
```

### 2.2.2. Cài đặt gói phát hành qua pip
```bash
pip install --upgrade litetorch
```

### 2.2.3. Kiểm tra cấu hình GPU
Đảm bảo trình biên dịch CUDA đã có trong biến môi trường hệ thống:
```bash
nvcc --version
```
Khi `nvcc` khả dụng trong biến `PATH`, LiteTorch sẽ tự động biên dịch và kích hoạt backend CUDA Native tăng tốc phần cứng.

---

## 2.3. Cài Đặt Trên Windows

### 2.3.1. Cài đặt công cụ biên dịch C++

Windows yêu cầu trình biên dịch C++ để liên kết các module mở rộng native. Chọn một trong hai phương án sau:

**Phương án A: Microsoft Visual C++ Build Tools (Khuyến nghị)**
Chạy lệnh PowerShell dưới quyền Quản trị viên (Administrator):
```powershell
winget install --id Microsoft.VisualStudio.2022.BuildTools --exact --force --override "--passive --wait --add Microsoft.VisualStudio.Workload.VCTools;includeRecommended"
```

**Phương án B: MinGW-w64 GCC**
1. Tải và cài đặt MinGW-w64 (GCC 10 trở lên).
2. Thêm đường dẫn thư mục `bin` của MinGW vào biến môi trường `PATH`.

### 2.3.2. Cài đặt qua pip
Mở Terminal hoặc Command Prompt và thực hiện:
```cmd
pip install --upgrade litetorch
```

---

## 2.4. Biên Dịch Từ Mã Nguồn (Build From Source)

Dành cho nhà phát triển muốn đóng góp mã nguồn hoặc tùy chỉnh nhân tính toán:

```bash
git clone https://github.com/nguyenminh20000/Litetorch-.git
cd Litetorch-
pip install -r requirements.txt
pip install -e .
```

Biên dịch bộ kiểm thử C++ bằng CMake:
```bash
mkdir build
cd build
cmake ..
cmake --build . --config Release
```

---

## 2.5. Các Biến Môi Trường Cấu Hình

| Tên biến | Giá trị mặc định | Giải thích chức năng |
| :--- | :--- | :--- |
| `LITETORCH_NO_NATIVE_GPU` | `0` | Đặt thành `1` để vô hiệu hóa CUDA/ROCm native và chuyển sang OpenCL hoặc CPU |
| `LITETORCH_RENDEZVOUS_FILE` | Không có | Đường dẫn tập tin dùng cho cơ chế rendezvous phân tán |
| `LITETORCH_NUM_THREADS` | Số core CPU | Số lượng luồng làm việc trong ThreadPool của CPU |

---

## 2.6. Kiểm Tra Môi Trường Cài Đặt

Chạy đoạn mã Python sau để xác nhận LiteTorch đã hoạt động chính xác:

```python
import litetorch as lt

is_gpu = lt.is_gpu_available()
backend = lt.get_backend_name()
device = lt.auto_device()

print(f"GPU Kha dung: {is_gpu}")
print(f"Backend dang su dung: {backend}")
print(f"Thiet bi mac dinh: {device}")

x = lt.Tensor.from_vector([1.0, 2.0, 3.0, 4.0], [2, 2], device, True)
y = lt.Ops.matmul(x, x)
loss = lt.Ops.sum(y)
loss.backward()

print("Kich thuoc ma tran ket qua:", y.shape)
print("Gia tri loss:", loss.item())
print("Gia tri dao ham cua x:", x.grad.to_vector())
```
