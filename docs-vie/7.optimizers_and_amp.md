# 7. Bộ Tối Ưu Hóa Và Huấn Luyện Độ Chính Xác Hỗn Hợp (AMP)

LiteTorch cung cấp các thuật toán tối ưu hóa bậc nhất và bậc hai, bao gồm các biến thể tiết kiệm bộ nhớ chuyên dụng cho mô hình lớn (8-bit, FP8, ZeRO-3) cùng hệ thống Automatic Mixed Precision (AMP).

---

## 7.1. Lớp Cơ Sở `lt.optim.Optimizer`

Mọi bộ tối ưu hóa đều kế thừa từ lớp cơ sở này và hỗ trợ các phương thức:
- `zero_grad()`: Xóa sạch gradient tích lũy trong các tham số (`p.grad = nullptr`).
- `step()`: Cập nhật trọng số theo đạo hàm và trạng thái nội bộ.
- `get_lr()` / `set_lr(new_lr)`: Lấy và điều chỉnh tốc độ học động.

---

## 7.2. Các Thuật Toán Tối Ưu Tiêu Chuẩn

### 7.2.1. `lt.optim.SGD`
```python
optimizer = lt.optim.SGD(model.parameters(), lr=0.01, momentum=0.9, weight_decay=1e-4)
```

### 7.2.2. `lt.optim.RMSprop`
```python
optimizer = lt.optim.RMSprop(model.parameters(), lr=0.001, alpha=0.99, eps=1e-8, weight_decay=0.0)
```

### 7.2.3. `lt.optim.Adam` & `lt.optim.AdamW`
AdamW phân tách rõ ràng giữa trọng số suy giảm (weight decay) và gradient:
```python
optimizer = lt.optim.AdamW(model.parameters(), lr=1e-4, beta1=0.9, beta2=0.999, eps=1e-8, weight_decay=0.01, offload_to_cpu=False)
```

---

## 7.3. Các Bộ Tối Ưu Hóa Tiết Kiệm VRAM Cho LLM

| Bộ tối ưu | Cú pháp khởi tạo | Đặc điểm tiết kiệm bộ nhớ |
| :--- | :--- | :--- |
| `lt.optim.AdamW8bit` | `AdamW8bit(params, lr=1e-3, beta1=0.9, beta2=0.999, eps=1e-8, weight_decay=0.01)` | Lượng tử hóa 8-bit động theo block cho moment 1 và moment 2, giảm 75% VRAM trạng thái optimizer |
| `lt.optim.AdamWFP8` | `AdamWFP8(params, lr=1e-3, beta1=0.9, beta2=0.999, eps=1e-8, weight_decay=0.01)` | Sử dụng định dạng FP8 E4M3/E5M2 cho bộ nhớ optimizer |
| `lt.optim.ZeRO3Optimizer` | `ZeRO3Optimizer(params, lr=1e-3, beta1=0.9, beta2=0.999, eps=1e-8, weight_decay=0.01)` | Phân mảnh trạng thái optimizer trên toàn bộ các GPU trong cluster |

```python
import litetorch as lt

params = model.parameters()
opt_8bit = lt.optim.AdamW8bit(params, lr=2e-4, weight_decay=0.01)
opt_fp8 = lt.optim.AdamWFP8(params, lr=2e-4, weight_decay=0.01)
```

## 7.4. Điều Chỉnh Tốc Độ Học (Learning Rate Schedulers)

### 7.4.1. `lt.optim.StepLR`
Giảm tốc độ học theo bội số bước:
```python
scheduler = lt.optim.StepLR(optimizer, step_size=30, gamma=0.1)
```

### 7.4.2. `lt.optim.CosineAnnealingLR`
Suy giảm tốc độ học theo hàm Cosine:
```python
scheduler = lt.optim.CosineAnnealingLR(optimizer, T_max=1000, eta_min=1e-6)
```

Cập nhật scheduler sau mỗi epoch:
```python
scheduler.step()
```

## 7.5. Automatic Mixed Precision (AMP) & GradScaler

Huấn luyện mô hình ở độ chính xác FP16/BF16 giúp tăng tốc độ tính toán lên gấp 2-3 lần và giảm 50% dung lượng VRAM.

`lt.amp.GradScaler` thực hiện co giãn giá trị loss động (Dynamic Loss Scaling) để ngăn chặn hiện tượng mất mát số học (underflow) ở định dạng FP16:

```python
import litetorch as lt

device = lt.auto_device()

model = lt.nn.Sequential([
    lt.nn.Linear(128, 256, True),
    lt.nn.GELU(),
    lt.nn.Linear(256, 10, True)
])
model.to(device)

optimizer = lt.optim.AdamW(model.parameters(), lr=1e-3)
scaler = lt.amp.GradScaler(init_scale=65536.0, growth_factor=2.0, backoff_factor=0.5, growth_interval=2000)
loss_fn = lt.nn.CrossEntropyLoss()

x = lt.Tensor.from_vector([0.5] * (32 * 128), [32, 128], device, False)
y = lt.Tensor.from_vector([1.0] * (32 * 10), [32, 10], device, False)

for step in range(5):
    optimizer.zero_grad()
    
    with lt.amp.AutocastGuard(True, lt.DataType.FP16):
        preds = model.forward(x)
        loss = loss_fn.forward(preds, y)
        scaled_loss = scaler.scale(loss)
    
    scaled_loss.backward()
    scaler.step(optimizer)
    scaler.update()
    
    print(f"Step {step + 1}, Loss: {loss.item():.4f}, Current Scale: {scaler.get_scale()}")
```
