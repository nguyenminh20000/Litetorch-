# 5. Danh Mục Toán Tử Tính Toán (litetorch.Ops)

Không gian tên `litetorch.Ops` chứa toàn bộ các toán tử đại số, hàm phi tuyến, hàm chuẩn hóa, hàm mất mát và các hạt nhân LLM tối ưu hóa.

---

## 5.1. Toán Tử Số Học Cơ Bản

| Toán tử | Chữ ký dữ liệu | Ý nghĩa |
| :--- | :--- | :--- |
| `Ops.add(a, b)` | `Tensor, Tensor -> Tensor` | Cộng hai tensor theo từng phần tử hoặc broadcasting |
| `Ops.sub(a, b)` | `Tensor, Tensor -> Tensor` | Trừ hai tensor |
| `Ops.mul(a, b)` | `Tensor, Tensor -> Tensor` | Nhân từng phần tử (Hadamard product) |
| `Ops.div(a, b)` | `Tensor, Tensor -> Tensor` | Chia từng phần tử |
| `Ops.matmul(a, b)` | `Tensor, Tensor -> Tensor` | Nhân hai ma trận 2D qua cuBLAS / OpenBLAS |
| `Ops.bmm(a, b)` | `Tensor, Tensor -> Tensor` | Nhân hàng loạt ma trận 3D `[B, M, K] x [B, K, N]` |

```python
import litetorch as lt

device = lt.auto_device()
a = lt.Tensor.from_vector([1.0, 2.0, 3.0, 4.0], [2, 2], device, False)
b = lt.Tensor.from_vector([5.0, 6.0, 7.0, 8.0], [2, 2], device, False)

add_res = lt.Ops.add(a, b)
mul_res = lt.Ops.mul(a, b)
matmul_res = lt.Ops.matmul(a, b)
```

## 5.10. Quản Lý Gradient & Cắt Chuẩn (Gradient Clipping)

```python
import litetorch as lt

device = lt.auto_device()

p1 = lt.Tensor.from_vector([10.0, 20.0], [2], device, True)
p2 = lt.Tensor.from_vector([30.0, 40.0], [2], device, True)

total_norm = lt.Ops.clip_grad_norm_([p1, p2], max_norm=1.0, norm_type=2.0)
print("Chuan gradient truoc khi cat:", total_norm)
```
