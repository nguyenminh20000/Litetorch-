# 10. Lượng Tử Hóa (Quantization) Và Biên Dịch JIT

LiteTorch hỗ trợ lượng tử hóa sau huấn luyện (Post-Training Quantization - PTQ), huấn luyện nhận biết lượng tử (Quantization-Aware Training - QAT) và hệ thống biên dịch đồ thị JIT (Just-In-Time Compilation).

---

## 10.1. Lượng Tử Hóa Nhận Biết Huấn Luyện (QATLinear)

`lt.quantization.QATLinear` thực hiện tính toán mô phỏng sai số lượng tử hóa số nguyên 8-bit hoặc 4-bit (Fake Quantization) trên cả trọng số và activation trong quá trình forward pass:

```python
import litetorch as lt

device = lt.auto_device()

raw_linear = lt.nn.Linear(512, 256, True)
raw_linear.to(device)

qat_layer = lt.quantization.QATLinear(
    raw_linear,
    w_scale=0.005,
    w_zp=0.0,
    a_scale=0.01,
    a_zp=0.0,
    b=8
)

x = lt.Tensor.from_vector([0.5] * (4 * 512), [4, 512], device, True)
out = qat_layer.forward(x)
loss = lt.Ops.sum(out)
loss.backward()

print("QAT Output Shape:", out.shape)
print("Weight grad:", qat_layer.weight.grad.to_vector()[:5])
```

## 10.2. Bộ Hiệu Chuẩn Lượng Tử Hóa (Calibrator)

Bộ hiệu chuẩn thu thập phân phối dữ liệu thực tế để tính toán tỷ lệ scale và zero-point tối ưu:

```python
import litetorch as lt

device = lt.auto_device()
calibrator = lt.quantization.Calibrator()

sample_act = lt.Tensor.from_vector([0.1, -0.5, 2.3, -1.8], [1, 4], device, False)
calibrator.collect("layer1_act", sample_act)

scale = calibrator.get_scale("layer1_act", bits=8)
params = calibrator.get_asymmetric_params("layer1_act", bits=8)
```

## 10.3. Nhân Ma Trận Int8 W8A8 & FP8 Scaled Matmul

```python
import litetorch as lt

device = lt.auto_device()

x_int8 = lt.Tensor.from_vector([10.0, 20.0, -15.0, 30.0], [2, 2], device, False, lt.DataType.INT8)
w_int8 = lt.Tensor.from_vector([5.0, -2.0, 1.0, 4.0], [2, 2], device, False, lt.DataType.INT8)

w8a8_out = lt.Ops.w8a8_matmul(x_int8, w_int8, x_scale=0.01, w_scale=0.02)
print("W8A8 result:", w8a8_out.to_vector())
```

## 10.4. Biên Dịch Đồ Thị Tính Toán JIT (JIT & Tracer)

LiteTorch tích hợp bộ phân tích biểu thức tượng trưng (Symbolic Tracer) và động cơ hợp nhất Kernel JIT (Kernel Fusion Engine) cho phép tự động biên dịch chuỗi phép toán nguyên tố thành một kernel C++/OpenCL/CUDA nguyên khối:

```python
import litetorch as lt

# Cach 1: Xay dung bieu thuc JIT truc tiep
v1 = lt.jit.JITVar(lt.jit.OpType.INPUT, "x")
v2 = lt.jit.JITVar(lt.jit.OpType.INPUT, "w")
expr = lt.jit.relu(v1 * 2.0 + v2)

jit_fn = lt.jit.JITFunction("fused_relu_add", expr, [v1, v2])

arg1 = lt.Tensor.from_vector([1.0, 2.0], [2], lt.auto_device(), False)
arg2 = lt.Tensor.from_vector([-3.0, 1.0], [2], lt.auto_device(), False)

res = jit_fn([arg1, arg2])
print("JIT output:", res.to_vector())

jit_fn.save("fused_relu.jit")
loaded_fn = lt.jit.JITFunction.load("fused_relu.jit")

# Cach 2: Tu dong truy vet ham Python bang Tracer
def custom_activation(args):
    return lt.Ops.gelu(lt.Ops.add(args[0], args[1]))

traced_fn = lt.jit.Tracer.trace([arg1, arg2], custom_activation, "traced_gelu")
traced_res = traced_fn([arg1, arg2])
print("Traced GELU output:", traced_res.to_vector())
```

## 10.5. Lượng Tử Hóa 4-Bit (NF4 & NVFP4)

LiteTorch hỗ trợ 2 định dạng 4-bit tiêu chuẩn:
- **`lt.DataType.NF4` (NormalFloat4)**: Tối ưu cho nén trọng số mô hình ngôn ngữ lớn (QLoRA).
- **`lt.DataType.FP4_E2M1` (NVFP4)**: Định dạng dấu phẩy động 4-bit theo chuẩn kiến trúc NVIDIA Blackwell B200 (1-bit dấu, 2-bit mũ, 1-bit định trị).

```python
import litetorch as lt

device = lt.auto_device()

w_fp32 = lt.Tensor.from_vector([0.1, -0.5, 1.2, -2.4], [2, 2], device, False, lt.DataType.FP32)
w_fp4 = w_fp32.cast(lt.DataType.FP4_E2M1)
w_nf4 = w_fp32.cast(lt.DataType.NF4)

print("FP4 dtype:", w_fp4.dtype)
print("NF4 dtype:", w_nf4.dtype)
```

## 10.6. JIT Autograd & Các Toán Tử Fused Có Sẵn

`JITFunction` được tích hợp toàn diện vào Autograd Engine của LiteTorch. Khi các tensor đầu vào có thuộc tính `requires_grad=True`, hệ thống tự động thiết lập đồ thị vi phân giải tích (Analytical Backward Graph):

```python
import litetorch as lt

device = lt.auto_device()

# Tensor can tinh gradient
x = lt.Tensor.from_vector([1.0, -2.0, 3.0], [3], device, True)
bias = lt.Tensor.from_vector([0.5, 0.5, 0.5], [3], device, True)

# Forward qua toan tu fused
out = lt.jit.fused_bias_gelu(x, bias)
loss = lt.Ops.sum(out)

# Lan truyen gradient qua JIT Kernel
loss.backward()

print("x.grad:", x.grad.to_vector())
print("bias.grad:", bias.grad.to_vector())
```

### Các toán tử Fused cấp cao hỗ trợ sẵn:
- `lt.jit.fused_bias_relu(x, bias)`: Gộp $(x + \text{bias}) \to \text{ReLU}$
- `lt.jit.fused_bias_gelu(x, bias)`: Gộp $(x + \text{bias}) \to \text{GELU}$
- `lt.jit.fused_residual_add(x, residual)`: Gộp phép cộng skip residual
- `lt.jit.fused_residual_gelu(x, residual)`: Gộp $(x + \text{residual}) \to \text{GELU}$
