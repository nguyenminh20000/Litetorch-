# 11. Quản Lý Dữ Liệu Và Lưu Trữ (Data & Serialization)

Tài liệu này hướng dẫn chi tiết về cấu trúc `Dataset`, bộ nạp dữ liệu đa luồng `DataLoader`, quản lý trạng thái checkpoint và lưu trữ tham số mô hình trong LiteTorch.

---

## 11.1. Lớp Cơ Sở Dataset

`lt.data.Dataset` là lớp cơ sở trừu tượng đại diện cho tập dữ liệu. Mọi tập dữ liệu tùy biến cần triển khai hai phương thức: `size()` (hoặc `__len__`) và `get(index)` (hoặc `__getitem__`).

```python
import litetorch as lt

class CustomTextDataset(lt.data.Dataset):
    def __init__(self, data_list):
        super().__init__()
        self.samples = data_list

    def size(self):
        return len(self.samples)

    def get(self, index):
        sample = self.samples[index]
        x_tensor = lt.Tensor.from_vector(sample[0], [len(sample[0])], lt.auto_device(), False)
        y_tensor = lt.Tensor.from_vector([sample[1]], [1], lt.auto_device(), False)
        return (x_tensor, y_tensor)
```

---

## 11.2. Tập Dữ Liệu TensorDataset

Đối với dữ liệu dạng ma trận đã nạp sẵn vào bộ nhớ, sử dụng trực tiếp `lt.data.TensorDataset`:

```python
import litetorch as lt

device = lt.auto_device()

x = lt.Tensor.from_vector([float(i) for i in range(100 * 32)], [100, 32], device, False)
y = lt.Tensor.from_vector([float(i % 2) for i in range(100)], [100, 1], device, False)

dataset = lt.data.TensorDataset(x, y)
print("Tong so mau:", dataset.size())
```

---

## 11.3. Bộ Nạp Dữ Liệu DataLoader

`lt.data.DataLoader` quản lý việc trộn dữ liệu (shuffle), gom cụm thành batch, prefetch đa luồng và chuyển dữ liệu sang thiết bị đích:

```python
import litetorch as lt

device = lt.auto_device()

dataset = lt.data.TensorDataset(x, y)
loader = lt.data.DataLoader(
    dataset=dataset,
    batch_size=16,
    shuffle=True,
    device=device,
    prefetch_limit=2
)

loader.reset()
while True:
    batch = loader.next()
    if batch is None:
        break
    bx, by = batch
    print("Batch x shape:", bx.shape, "Batch y shape:", by.shape)
```

### 11.3.1. Lưu và khôi phục trạng thái DataLoader
Khi huấn luyện mô hình lớn bị ngắt quãng giữa chừng, trạng thái con trỏ và seed ngẫu nhiên của `DataLoader` có thể được lưu lại:

```python
loader.save_state("dataloader_checkpoint.bin")
loader.load_state("dataloader_checkpoint.bin")
```

## 11.4. Lưu Trữ Trọng Số Mô Hình Và Bộ Tối Ưu Hóa (Serialization)

LiteTorch cung cấp giao diện cấp cao `lt.save` và `lt.load` hỗ trợ lưu trực tiếp các đối tượng `Module`, danh sách `Tensor` hoặc `Optimizer`:

### 11.4.1. Lưu và nạp toàn bộ Module
```python
import litetorch as lt

model = lt.nn.Sequential([
    lt.nn.Linear(32, 64, True),
    lt.nn.ReLU(),
    lt.nn.Linear(64, 2, True)
])

lt.save(model, "model.lt")
lt.load(model, "model.lt")
```

### 11.4.2. Lưu và nạp trạng thái Optimizer
```python
optimizer = lt.optim.AdamW(model.parameters(), lr=1e-3)

lt.save(optimizer, "optimizer.lt")
lt.load(optimizer, "optimizer.lt")
```

### 11.4.3. Các hàm nguyên thủy cấp thấp
- `lt.save_parameters(params, filepath)`
- `lt.load_parameters(params, filepath)`
- `lt.save_optimizer_state(optimizer, filepath)`
- `lt.load_optimizer_state(optimizer, filepath)`
